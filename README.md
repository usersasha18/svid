# Приглашение на свидание

Нужен Node.js 18 или новее (для встроенного `fetch`; проверено на Node.js 22). Токен Telegram хранится только в серверном `.env` и не должен попадать во фронтенд или GitHub.

## Локальный запуск на macOS / Linux

1. В Telegram откройте своего бота и отправьте ему `/start`.
2. Получите `chat_id`: откройте `https://api.telegram.org/bot<ВАШ_НОВЫЙ_ТОКЕН>/getUpdates` и найдите `message.chat.id`. Не делитесь ссылкой или ответом: в URL находится токен.
3. Скопируйте `.env.example` в `.env`, откройте `.env` в редакторе и укажите новый `TELEGRAM_BOT_TOKEN` и свой `TELEGRAM_CHAT_ID`.
4. В терминале перейдите в папку проекта, затем выполните:

   ```sh
   set -a
   source .env
   set +a
   node server.js
   ```

5. Откройте `http://localhost:3000`. Остановка сервера: `Ctrl+C`.

Если порт 3000 занят, укажите другой в `.env` (например, `PORT=3001`) и откройте соответствующий адрес.

## Локальный запуск на Windows PowerShell

Создайте `.env` на основе `.env.example`, заполните переменные, затем выполните:

```powershell
Get-Content .env | ForEach-Object {
  if ($_ -match '^\\s*([^#=]+)=(.*)$') {
    [Environment]::SetEnvironmentVariable($matches[1].Trim(), $matches[2].Trim(), 'Process')
  }
}
node server.js
```

## Проверка

На странице можно выбрать один, несколько или все варианты («Хочу всё!»). После нажатия «Да» выбранные планы придут в Telegram вместе с ответом. На «Нет» тоже отправляется уведомление и выбранные планы. Если ничего не выбрано, приходит только ответ. Получатель должен предварительно написать боту `/start`. Если сервер отвечает ошибкой Telegram, проверьте токен и `chat_id` в `.env`.

GitHub Pages размещает только статические файлы и не запускает `server.js`. Локальный сервер доступен только на этом компьютере; для публичного сайта сервер нужно отдельно разместить на Node.js-хостинге.
