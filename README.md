# Приглашение на свидание

Нужен Node.js 18 или новее (встроенный `fetch`). Токен Telegram хранится только на сервере.

## Запуск

1. В Telegram откройте своего бота и отправьте ему `/start`.
2. Получите свой `chat_id`: откройте в браузере `https://api.telegram.org/bot<ВАШ_НОВЫЙ_ТОКЕН>/getUpdates` и найдите `message.chat.id` в ответе. Не делитесь этой ссылкой/ответом: в URL есть секретный токен.
3. Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
4. Запустите из этой папки:

   ```sh
   set -a; source .env; set +a; node server.js
   ```

5. Откройте `http://localhost:3000`. Чтобы сайт видели другие люди, разместите его вместе с сервером на хостинге, поддерживающем Node.js, и установите там те же переменные окружения. Сам по себе локальный сервер доступен только на вашем компьютере.

Нажатие «Да» отправляет уведомление и затем показывает подтверждение; нажатие «Нет» тоже уведомляет, что ответ был нажат, при этом кнопка продолжает убегать. Токен нельзя добавлять в `index.html` или публиковать.
